# MVP Agent: Калькулятор суточной нормы калорий и БЖУ

## Назначение проекта
Агент помогает пользователю рассчитать суточную норму калорий и соотношение макронутриентов (белки, жиры, углеводы) на основе антропометрических данных и уровня физической активности.

## Возможности
- Извлечение параметров из естественного языка (пол, возраст, вес, рост, активность).
- Математический расчёт по формуле Миффлина-Сан Жеора.
- Валидация входных данных (защита от отрицательных значений и некорректных форматов).
- Формирование структурированного и понятного ответа.

## Архитектура
Пользователь (CLI) → LLM (извлечение сущностей) → Tool `calculate_macros` (математика и валидация) → LLM (форматирование ответа) → Пользователь.

## Структура проекта
- `src/cli.py` - Точка входа, консольный интерфейс.
- `src/agent.py` - Ядро агента, оркестрация LLM и Tools.
- `src/tools.py` - Реализация инструмента `calculate_macros`.
- `src/prompts.py` - Системные инструкции для LLM.
- `tests/run_scenarios.py` - Скрипт автоматической проверки сценариев.
- `data/test_results.json` - Отчёт о прохождении тестов.

## Установка
1. Распакуйте архив и перейдите в папку проекта.
2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

3. Установите зависимости:
   pip install -r requirements.txt

## Настройка переменных окружения
1. Создайте файл .env в корне проекта (или скопируйте .env.example).
2. Откройте .env и укажите ваш ключ :
   OPENAI_API_KEY=sk*

## Запуск 
Для запуска интерактивного режима в консоли:
- `python -m src.cli`

## Проверка (Тестирование) 
Для автоматического прогона основного и ошибочного сценариев выполните:
- `python tests/run_scenarios.py`
